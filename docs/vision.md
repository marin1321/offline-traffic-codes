# Vision

> Decisions: [`../CONTRATO.md`](../CONTRATO.md).

## Problem

A **traffic officer**, when writing a **comparendo** (citation), needs the correct **infraction code** and its meaning—quickly, often **without internet**.

## Users

| Type | Description | Primary need | Status |
| --- | --- | --- | --- |
| Primary (only role) | Traffic officer | Find code + read description offline | Decided |
| Pilot | Promoter’s father (Android) | Use the app in the field | Decided |
| Out of scope | iPhone-only users, general public, store mass market, multi-role | — | Decided |

## Context

- **Country:** Colombia  
- **Platform:** Android only (APK)  
- **Stack:** Flutter  
- **Nature:** experimental / customized  
- **Catalog:** hybrid seed + remote JSON  
- **Legal:** informational; disclaimer (D-022)  
- **Portfolio docs:** English; **in-app UI:** Spanish  

## Value proposition

For **traffic officers** (pilot: one officer on Android) who need the right code for a citation, this app is an **offline consultation** tool with categories and search by code or description.

## Non-goals

- iOS / App Store / Play Store  
- User backend / fine payments / SIMIT  
- AI
